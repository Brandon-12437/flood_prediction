About FloodGuard AI

FloodGuard AI is a machine learning system designed to estimate flood risk using environmental, infrastructure, climate and community-related factors.

Machine Learning

The prediction engine uses an XGBoost regression model trained on historical flood-related data.

20 Risk Factors

The system evaluates factors including rainfall intensity, drainage, river management, deforestation and infrastructure.

Real-Time API

Predictions are sent to a Flask API and returned to the website instantly.
